# Learning (Layer 4)

Feedback from real technology investigations. Entrepreneurs record five simple outcomes; those answers improve future recommendations when enough similar cases exist.

## What is recorded

- Laboratory / owner response
- License availability
- Technical due diligence result
- SBIR/STTR award result
- Customer interest

## Privacy

- Each user’s rows are private (RLS).
- Cohort insights return **counts only** (no notes, URLs, names, or ids) from rows with `contribute_to_learning` and not sample data.
- Sample / demo technologies never contribute to cohort learning.

## Consumers

- Backend: `/learning/*` routes
- App: outcomes form on a technology, compare ranking, next-action hints
- Shared helpers: `@project/learning`
